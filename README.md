# Карточка с рынка: Telegram Mini App для InSales

Прототип ручного режима. Вы на рынке фотографируете товар в Telegram Mini App,
пишете пару слов и закупочную цену. Приложение через Claude собирает карточку
(название, описание, категория, коллекции), считает розничную цену по формуле,
при желании подбирает фото товара в интернете и создаёт товар в InSales через API.
Домой ничего доделывать не нужно.

Автоматический режим из канала поставщика в Telegram это следующий этап.
Архитектура под него уже заложена: Claude-разбор, цены и InSales общие,
меняется только источник фото и текста.

## Как это работает

1. В Telegram открываете бота, кнопка меню «Новый товар» открывает Mini App.
2. Снимаете 1-6 фото, пишете заметку («футболка хлопок, S-XL»), указываете закупку.
3. Бэкенд отправляет фото и заметку в Claude. Ответ строго по JSON-схеме:
   название, описание в HTML, категория и коллекции из вашего списка,
   поисковый запрос для картинок, что осталось непонятным.
4. Розница считается по правилам из `config.yaml` (наценка по диапазонам,
   минимальная маржа, округление вверх). Артикул генерируется автоматически.
5. Если включён поиск картинок, бэкенд ищет фото по запросу, Claude сверяет
   кандидатов с вашим снимком и оставляет только тот же самый товар.
6. Вы видите превью: правите любое поле руками или пишете правку словами
   («это детская модель»), Claude пересобирает карточку.
7. «Опубликовать»: товар создаётся в InSales (по умолчанию скрытым),
   загружаются фото, товар добавляется в коллекции. Приходит ссылка на админку.

## Структура

```
app/
  main.py          FastAPI: /api/drafts, /revise, PATCH, /publish, картинки, авторизация
  claude_parser.py Claude: фото + заметка -> ProductDraft; сверка картинок-кандидатов
  insales.py       Клиент InSales API v2 (единственное место контакта с магазином)
  pricing.py       Розница из закупки по правилам config.yaml
  image_search.py  Поиск фото: Google Custom Search или SerpAPI (по желанию)
  telegram_auth.py Проверка подписи initData Telegram Mini App
  drafts.py        Черновики на диске: data/drafts/<id>/
  config.py        .env (секреты) + config.yaml (бизнес-правила)
webapp/            Mini App: index.html, app.js, style.css (без сборки)
scripts/
  setup_bot.py     Один раз: повесить на бота кнопку меню с Mini App
  bot.py           Необязательный бот: отвечает на /start кнопкой
tests/             pytest, всё внешнее подменено
```

## Запуск

Нужны: Python 3.11+, токен бота, ключ API InSales, ключ Anthropic,
публичный HTTPS-адрес (Telegram открывает Mini App только по https).

```bash
pip install -r requirements.txt
cp .env.example .env        # заполнить
# config.yaml: наценки, стиль описания, категории (или оставить пустыми, подтянутся из InSales)
python -m pytest -q
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Для теста с телефона без сервера: `cloudflared tunnel --url http://localhost:8000`
или `ngrok http 8000`, полученный https-адрес записать в `PUBLIC_BASE_URL`, затем:

```bash
python scripts/setup_bot.py     # кнопка меню в боте
```

Docker: `docker compose up -d --build`.

### Порядок первого запуска

1. `INSALES_DRY_RUN=true`. Приложение работает полностью, но в магазин не пишет,
   payload печатается в лог. Так проверяются описания, категории и цены.
2. Сверить поля API в шапке `app/insales.py` с актуальной документацией
   https://api.insales.ru (при разработке сайт был недоступен, поля записаны по
   памяти: `category_id`, `variants[].price/sku/quantity`, `images.json` с
   `attachment` base64, `collects.json`). Если что-то отличается, правка в одном файле.
3. `INSALES_DRY_RUN=false`, `create_hidden: true` в `config.yaml`. Товары
   создаются скрытыми, вы включаете их в админке после проверки.
4. Когда доверие появилось, `create_hidden: false`.

### Доступ

В приложение пускаются только Telegram-аккаунты из `ALLOWED_TELEGRAM_USER_IDS`.
Подпись `initData` проверяется на каждом запросе по алгоритму Telegram.
`ALLOW_UNAUTHENTICATED=true` отключает проверку для отладки в обычном браузере,
на сервере держать `false`.

## Поиск фото в интернете

Выключен по умолчанию (`IMAGE_SEARCH_PROVIDER=none`): тогда в карточку идут ваши снимки.

- `google`: Google Custom Search JSON API, ключ и `cx` поисковой системы с
  включённым поиском картинок. Бесплатно 100 запросов в день.
- `serpapi`: ключ serpapi.com, движок google_images.

Кандидатов сверяет Claude по вашему фото, берутся только совпадающие (до
`image_search.max_selected`). Чужие фото могут быть защищены авторским правом:
безопаснее использовать фото производителя или поставщика.
